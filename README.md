# «Мой книжный прогноз» — PWA MVP

Рабочая статическая PWA-версия персонального книжного приложения. Оптимизирована под iPhone 15 Pro и учитывает верхнюю и нижнюю безопасные зоны iOS.

## Что уже работает

- Главная страница и нижняя навигация.
- Списки «Хочу прочитать» и «Прочитано».
- Поиск, фильтры по году и произвольному периоду, формату, источнику, оценке и уверенности.
- Сортировка, включая дату добавления, дату прочтения и длительность нахождения в «Хочу».
- Карточка персонального прогноза: оценка, диапазон, вероятность, уверенность, объяснения и риски.
- Карточка прочитанной книги и анкета впечатлений.
- Оценка с шагом 0,5, причины, характеристики, ожидания, комментарий, признак «плохо помню».
- Разделение «текст / аудио» и оценка чтеца.
- Автоматический пересчёт прогнозов и история существенных изменений.
- Профиль вкуса и базовая аналитика точности.
- Ручное добавление, добавление по ссылке.
- Импорт Excel LiveLib/Яндекс Книг по колонкам «Книга» и «Автор».
- Поиск дублей и подтверждение объединения.
- Распознавание скриншота через Tesseract.js с обязательной ручной проверкой.
- Ручная резервная копия JSON и восстановление.
- Локальное хранение без входа.

## Ограничения первой версии

- Прямая авторизованная синхронизация с LiveLib и Яндекс Книгами не подключена: для неё нужен отдельный серверный интеграционный слой и исследование доступных методов.
- Кнопка «Обновить» пересчитывает персональные прогнозы. Новые оценки сайтов появляются после повторного импорта.
- Получение ссылки через системное меню «Поделиться» на iPhone не гарантируется для PWA. Используется копирование и вставка ссылки.
- OCR скриншотов загружает языковые модели через интернет и может ошибаться.
- Данные хранятся в браузере, поэтому резервную копию нужно сохранять в iCloud Drive или «Файлы».

## Как запустить локально

Из папки проекта:

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Для установки на iPhone приложение должно быть размещено на HTTPS-хостинге.

## Как разместить

Содержимое папки можно опубликовать как статический сайт в Netlify, Vercel, Cloudflare Pages или GitHub Pages. Сборка не требуется.

После публикации открыть адрес в Safari на iPhone → «Поделиться» → «На экран Домой».

## Демонстрационные данные

В стартовую сборку включена ограниченная демонстрационная выборка из пользовательских списков. После импорта полных Excel-файлов демо-режим отключается.

## Версия 1.1 — исправления первого теста

- Исправлен импорт дат из Excel: поддерживаются Excel-даты, `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, даты с русским названием месяца и год без точной даты.
- Некорректные значения даты больше не останавливают весь импорт.
- Исправлена вёрстка причин впечатления на компьютере и iPhone: чекбокс больше не растягивается на всю строку, подписи читаются полностью.
- На узком экране причины показываются по одной в строке.
- Быстрые фильтры стали взаимоисключающими: повторное нажатие отключает фильтр, выбор другого заменяет предыдущий.
- Убрано приветствие «Доброе утро».
- В настройках отображается номер версии.
- Service Worker переведён на получение свежих файлов из сети с резервным использованием кэша.

## Как обновить версию на GitHub Pages

1. Создать резервную копию данных в приложении.
2. В репозитории GitHub выбрать **Add file → Upload files**.
3. Перетащить содержимое новой папки поверх старых файлов и подтвердить **Commit changes**.
4. Подождать публикацию GitHub Pages.
5. На iPhone полностью закрыть приложение и открыть снова. При необходимости открыть адрес в Safari и обновить страницу ещё раз.
